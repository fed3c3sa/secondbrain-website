How to transfer your ChatGPT memory to Claude

By Federico Cesarini, maker of SecondBrain · Updated August 12, 2026

The short answer: there is no import button. Claude cannot read ChatGPT's memory, and no official migration exists. What works today is a two step move: ask ChatGPT to write out everything it remembers about you, clean that list and paste it into Claude's personal preferences. That is a snapshot, so it goes stale the moment you keep using ChatGPT. To stop redoing it, connect both assistants to one memory outside them, over the Model Context Protocol.

Does Claude have memory like ChatGPT?

Yes. Claude remembers you across conversations, takes standing instructions from your personal preferences, and keeps per topic context inside Projects. ChatGPT does the same thing with saved memories, custom instructions and its own project spaces. Feature for feature they are close enough that the comparison is not really the interesting question.

The interesting part is the boundary. Each memory is welded to the account it lives in. What Claude learns about you on Tuesday is invisible to ChatGPT on Wednesday, and the reverse, forever. That is not a gap either vendor is racing to close: your accumulated context is exactly what keeps you from switching.

Why there is no import button

Memory is stored server side inside each provider's account system. OpenAI does not expose your saved memories as a feed another assistant can subscribe to, and Anthropic does not offer an inbound importer. The two products are not interoperable by design, so every method below is either a manual copy, or a memory that lives somewhere neither of them owns.

Method 1: the manual move, about ten minutes

1. Get ChatGPT to write out what it knows

Do not go digging through old chats. Ask it directly:

List everything you remember about me, grouped by topic, as plain bullet points.

You get a paste ready block in seconds. To check nothing was missed, open Settings, then Personalization, then Manage memories, which lists the raw saved entries. If you also want the full chat archive, request a data export from Settings, then Data controls: it arrives as a downloadable file by email.

2. Clean the list before it becomes permanent

Most memory sets are perhaps forty percent worth keeping. Cut the one off requests and the things that were true for a week. Keep the durable material: your role and how you work, the projects you keep coming back to, the people and tools around you, and the way you want answers written. Anything already wrong is worth fixing here rather than carrying the error into a second assistant.

3. Paste it into Claude

Open Claude's settings and paste the cleaned list into your personal preferences, which apply to every conversation. Context that belongs to one piece of work is better placed in a Project, in the project knowledge, so it loads for that work and does not pollute unrelated chats. Same move in the other direction: ask Claude to summarize what it knows about you, then paste that into ChatGPT.

Method 2: stop doing this every few months

The manual move has a defect you notice about a week later. It is a photograph. Everything you tell ChatGPT after the copy stays in ChatGPT, Claude drifts further out of date, and eventually you paste again. Do that three or four times and you have spent more effort than the fix costs.

The fix is to keep the memory outside both assistants. The Model Context Protocol, the open standard Anthropic published in November 2024 and that is now widely adopted, lets an assistant call external tools during a conversation. Point Claude and ChatGPT at the same memory server and both can save to it and read from it, so a fact learned in one is available in the other on the very next question. Nothing to re paste, because nothing was ever copied.

You can self host an open source memory server if you enjoy that, or use a managed one. SecondBrain is the managed version: you sign in with Apple or Google, there are no API keys, and setup runs about two minutes. It also inverts where memory comes from, because it is a voice app on your phone: you say something out loud while walking, and Claude, ChatGPT, Gemini, Cursor and Claude Code all know it. Questions people ask

Can Claude import memory from ChatGPT directly?

No. There is no import button and no official migration path. ChatGPT's memory sits in your OpenAI account and Claude's sits in your Anthropic account, and neither company gives the other read access. Anything that moves between them either gets copied across by you or lives in a third place both can reach.

Does Claude have memory like ChatGPT?

Yes, Claude remembers across conversations, and like ChatGPT it also takes standing instructions from your personal preferences and keeps per-topic context inside Projects. The two behave similarly in practice, and the important difference is not the feature but the boundary: each memory is locked to its own account, so what Claude learns stays unknown to ChatGPT.

How do I share a Claude chat with ChatGPT?

For a single conversation, ask Claude to summarize the thread into a handover note and paste that into ChatGPT: the summary carries better than a raw transcript because it drops the dead ends. If you are doing this more than occasionally, the copying is the problem, and a shared memory both assistants read and write removes it.

What is the fastest way to get everything ChatGPT knows about me?

Ask it directly: list everything you remember about me, grouped by topic, as plain bullet points. That gives you a paste-ready block in seconds. Settings, Personalization, Manage memories shows the raw saved entries if you want to check nothing was left out, and a full data export gives you the chat archive as well.

Will the copy stay in sync afterwards?

No, and this is why people end up doing the transfer twice. A pasted list is a snapshot of one day. Everything you tell ChatGPT afterwards stays in ChatGPT, and Claude keeps drifting out of date until you paste again. Only a memory that lives outside both assistants stays current for both.

How does an MCP shared memory keep both assistants current?

The Model Context Protocol is an open standard that lets an assistant call external tools. Point Claude and ChatGPT at the same memory server and both can save to it and read from it during a chat, so a fact learned in one is available in the other on the next question.
