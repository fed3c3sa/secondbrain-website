How to build a second brain in Obsidian, and feed it from your phone

By Federico Cesarini, maker of SecondBrain · Updated November 4, 2026 · 12 min read

In short: Obsidian is one of the best homes for a second brain: it is free, it keeps every note as a plain Markdown file in a folder you own, and AI agents such as Claude Code can work on that folder. Start with five folders, daily notes and one capture habit, and add plugins only when you miss something. On iPhone with iOS 26 or later, Quick Capture and Voice Capture put typed or spoken notes straight into your vault; what Obsidian leaves to you is the filing. SecondBrain does that part: you talk, it writes the note, files it and sets reminders, and with SecondBrain Pro you can bring the notes into your vault as Markdown, by exporting on iPhone or asking Claude Code over MCP.

Is Obsidian good for a second brain?

Yes, if you want to own your notes and do not mind shaping the system yourself. Obsidian keeps every note as a plain Markdown file in a folder on your device, which it calls a vault (Obsidian Help), links notes in both directions (backlinks), and has been free for personal and work use since February 2025 (Obsidian's announcement). It keeps whatever you give it. The filing is up to you.

What makes it a strong home for a second brain:

  • Files you own. Plain Markdown opens in any text editor and will outlive any app, Obsidian included.
  • Links that work both ways. Link one note to another and the second shows the link back, so ideas find each other over time.
  • It grows with you. Built-in features cover daily notes, templates, properties, database views and visual boards, and community plugins cover the rest.
  • It is ready for AI. Because the vault is just a folder, an agent such as Claude Code can read and edit it, which is the idea behind the AI second brain setups people build on Obsidian.

And where it asks more of you: the setup and upkeep are yours, nothing gets filed unless you file it, phone capture depends on your platform, and syncing the vault across devices means paying for Obsidian Sync or setting up another method yourself.

Obsidian or Notion? Notion is a cloud workspace built around shared pages and databases, and it shines when a team edits together. Obsidian is built around one person's files and links. If owning your notes matters most, Obsidian is the natural pick for a personal second brain.

How to set up an Obsidian second brain, step by step

Setting up an Obsidian second brain can take under an hour if you resist the urge to perfect it: one vault, five folders, a daily note, a few properties, capture on your phone, sync, and a weekly review. Everything else can wait until you have a hundred notes and know what you actually miss.

  1. Create one vault. Install Obsidian on your computer and your phone and create a single vault, the folder that holds every note. One vault for your whole life is easier to search and link than several.
  2. Make five folders. Create 0 Inbox, 1 Projects, 2 Areas, 3 Resources and 4 Archive. That is Tiago Forte's PARA method with an inbox in front, which Forte designed to work across any platform.
  3. Turn on daily notes and templates. Both are core plugins. Give the daily note a template with a Captured heading, so anything you jot down during the day has one obvious home.
  4. Add a few properties. Give project notes properties such as status and due date, then create a base to see them as a table or cards, with no community plugin.
  5. Set up capture on your phone. On iPhone with iOS 26 or later, put Quick Capture on the Lock Screen and send captures to today's daily note or a new note in 0 Inbox; on Android, add an Obsidian widget. For web pages, install the official Web Clipper.
  6. Sync the vault to your phone. Use Obsidian Sync, from 4 dollars per user per month billed yearly, or a sync method you set up yourself, so the same vault opens everywhere.
  7. Review once a week. Empty the Inbox into a project, an area, a resource or the archive, and delete what no longer matters. Ten minutes is enough.

PARA, Zettelkasten or no folders: which structure fits?

Use PARA folders for the things you act on and links for ideas, and do not argue about structure before you have a hundred notes. PARA sorts notes by what you are doing with them; a Zettelkasten builds a web of small linked idea notes; a flat vault skips folders and relies on links and search. All three work in Obsidian.

Which Obsidian plugins does a second brain need?

Fewer than the setup videos suggest. The core plugins that ship with Obsidian cover a working second brain: daily notes, templates, properties with Bases views and Canvas, plus Obsidian's free Web Clipper browser extension for web pages. Add a community plugin only when you can name the problem it solves, because each one is another thing to update and trust.

How do you capture into Obsidian from your phone?

Capturing is not filing

A transcript in your daily note is a start, not a second brain. Someone still has to give it a title, file it and turn "dentist Thursday at ten" into an actual reminder. That is the step most people skip, and it is why so many vaults turn into an inbox nobody empties.

SecondBrain does that step. You tap and talk on iPhone, Android or the web; it writes a clean note, files it in the right folder and creates the calendar event or reminder you asked for. To bring those notes into Obsidian there are two routes, both with SecondBrain Pro:

  • Export. On iPhone, Settings, Export all notes gives you a .zip with one Markdown file per note in the same folder tree as the app. Unzip it into your vault and the notes open straight away, with no plugin.
  • Claude Code. Connect SecondBrain to Claude Code over MCP, start Claude Code in your vault, and ask it to file your latest notes into 0 Inbox. It reads your SecondBrain notes and writes Markdown files where you tell it.

Neither is a live sync: you decide when notes move, and your vault stays yours.

How do you connect Claude Code to your Obsidian vault?

Open a terminal in your vault folder and start Claude Code: it reads and edits the Markdown files directly, and a CLAUDE.md file in the vault tells it your folders and rules at the start of every session (Claude Code docs). For other MCP clients, the community Local REST API plugin runs an MCP server inside Obsidian while it is open on your computer; Claude Desktop connects through the mcp-remote bridge, which needs Node.js.

  • Write the rules once. In CLAUDE.md, list your five folders, what belongs in each, how you name notes and which folders to leave alone. CLAUDE.md guides the agent but locks nothing, so keep notes it must never read out of the vault. It is the schema in Andrej Karpathy's LLM Wiki pattern, where an agent keeps a wiki of linked Markdown pages up to date as you add sources.
  • Borrow a starting point. Community projects give you one: claude-obsidian is built on Karpathy's pattern, and obsidian-second-brain keeps a Markdown memory for Claude Code and other agents in your vault. They are independent projects, not made by Obsidian, so read what they change before running them.
  • Stay inside Obsidian if you prefer. The Copilot plugin runs Claude Code, Codex or OpenCode inside Obsidian.
  • Protect the vault. Keep a backup or version history before an agent edits your notes, and remember that anything it reads goes to the model provider. Pages you clip from the web can also carry instructions written for AI, so review what an agent did after it reads them.

Can AI organize the whole vault for you? It can file, link and summarize, and the LLM wiki pattern does exactly that. The risk is the one every second brain faces: an agent that files everything can bury you in pages you never read, what Christian Tietze calls the collector's fallacy, at machine speed. Let it file what you chose to keep, not everything you ever saw. Our AI second brain guide compares this route with the others.

Mistakes that kill an Obsidian second brain

  • Collecting plugins instead of notes. Every plugin adds settings, updates and things that can break. Start with the core ones.
  • Perfecting the structure first. A beautiful empty vault is still empty. Capture for two weeks, then decide what structure you need.
  • Capturing without reviewing. An Inbox that only grows becomes a junk drawer. The ten-minute weekly review is the habit that keeps the rest alive.
  • No backup. Your vault is just files, which makes it easy to back up. Do it, especially before letting an AI agent edit them.
  • Typing everything on the phone. If capture is slow, you stop capturing. Speak instead, whether through Voice Capture or an app built for it.

Questions people ask

Is Obsidian free?

Yes. Since February 20, 2025, Obsidian has been free for personal, commercial and non-profit use, with an optional Commercial license for organizations that want to support it. You pay only for add-ons: Sync starts at 4 dollars per user per month billed yearly, and Publish at 8 dollars per site per month billed yearly. For capture that files itself, SecondBrain's free plan holds 10 notes and allows up to 3 AI requests a day.

Do you need to code to build an Obsidian second brain?

No. Folders, daily notes, templates and properties are all point and click, and many people never install a community plugin. Code only comes in if you want an AI agent such as Claude Code working on the vault, and even then you mostly write instructions in plain English. If you would rather skip setup, SecondBrain files notes from your voice, and with SecondBrain Pro they can come into Obsidian as Markdown.

Can Obsidian transcribe voice notes?

On iPhone with iOS 26 or later, yes: since version 1.15, released on November 2, 2026, Quick Capture's Voice Capture transcribes as you speak and can keep the recording. The Audio recorder core plugin only records, and the community Whisper plugin transcribes through OpenAI, Groq, Azure or another Whisper-compatible API with your own key. Filing is still up to you, though; SecondBrain turns what you say into a titled note in the right folder, with any reminder set.

How do I capture into Obsidian on Android?

Open Obsidian from a home screen widget, a Quick Settings tile or an app shortcut and type, or record with the Audio recorder, which does not transcribe. Quick Capture and Voice Capture are documented only for iOS. If you capture by voice on Android, SecondBrain writes and files the note there, and with SecondBrain Pro, Claude Code can read those notes and write them into your vault when you ask.

Can Claude read my Obsidian vault?

Yes. Claude Code works directly on the Markdown files when you start it in the vault folder, and a CLAUDE.md file there tells it your rules. Other MCP clients can reach the vault through the community Local REST API plugin while Obsidian is open on your computer, and Claude Desktop can too through the mcp-remote bridge. Whatever the agent reads goes to the model provider, so keep private notes out of the folder you open it in. With SecondBrain Pro, Claude can also read the notes you captured by voice on your phone.

Is Obsidian better than Notion for a second brain?

For one person who wants to own their notes, usually yes: Obsidian stores plain Markdown files on your device and links notes in both directions, while Notion is a cloud workspace built around shared pages and databases. Notion wins when a team edits together. Either way, the habit matters more than the app, and SecondBrain makes the habit easy by turning a few spoken words into a filed note.
